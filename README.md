# MassUp AI — персональный Telegram-бот для набора веса

Telegram-бот + Mini App + SQLite + AI-анализ еды, персональный тренер,
аналитика прогресса, напоминания и недельное меню по бюджету.

## Что уже работает

- персональный доступ по Telegram ID;
- анкета и расчёт суточной нормы по Mifflin–St Jeor;
- умеренный профицит для плавного набора веса;
- дневник калорий, белков, жиров и углеводов;
- добавление еды вручную;
- анализ фотографии блюда с компонентами, граммовкой, КБЖУ и уверенностью;
- возможность удалить или исправить AI-оценку через API;
- меню на 7 дней под бюджет, предпочтения, аллергии и продукты дома;
- список покупок, примерные цены, рецепты и план готовки;
- запись веса и простая диаграмма прогресса;
- прогноз даты достижения цели, серии дней и достижения;
- недельный отчёт по дневнику и изменению веса;
- умный добор оставшихся калорий и белка;
- AI-рецепт из продуктов дома, замена блюда и пересчёт порции;
- AI-разбор дневного рациона и ответы тренера;
- чтение КБЖУ, состава и аллергенов с фотографии этикетки;
- добровольные напоминания о еде, взвешивании и недельном отчёте;
- защищённая админ-панель со статистикой пользователей, активности и AI-запросов;
- отправка фото прямо в Telegram;
- фраза «4500 рублей на неделю» и команда `/plan 4500`;
- Docker и автотесты.

## Быстрый локальный запуск в Windows / PyCharm

Самый простой способ: дважды нажмите `УСТАНОВИТЬ_WINDOWS.bat`, после установки заполните `.env`, затем нажмите `ЗАПУСТИТЬ_WINDOWS.bat`.

Ручной способ:

1. Откройте папку проекта в PyCharm.
2. Откройте Terminal и выполните:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
Copy-Item .env.example .env
```

3. Откройте `.env` и добавьте ключи. Для первого запуска можно оставить `BOT_TOKEN` и `OPENAI_API_KEY` пустыми: интерфейс, профиль, ручной дневник и расчёты будут работать, но AI-функции будут ждать ключ.
4. Запустите:

```powershell
python run.py
```

5. Откройте `http://localhost:8000`.

## Переменные `.env`

- `BOT_TOKEN` — токен, полученный у BotFather.
- `OWNER_TELEGRAM_ID` — ваш цифровой Telegram ID для защищённых команд `/backup` и `/restore`.
- `PUBLIC_ACCESS` — `true`, чтобы открыть обычные функции бота и Mini App всем пользователям, сохранив административные команды только для владельца.
- `OPENAI_API_KEY` — ключ OpenAI API; подписка ChatGPT и API оплачиваются отдельно.
- `OPENAI_MODEL` — модель с поддержкой изображений и Structured Outputs. По умолчанию стоит экономичная `gpt-5.6-luna`.
- `WEBAPP_URL` — публичный HTTPS-адрес приложения. Telegram Mini App не открывает обычный локальный адрес на чужом устройстве.
- `DEV_MODE` — `true` только для локальной проверки; на сервере обязательно `false`.

## Команды Telegram

- `/today` — текущие КБЖУ;
- `/suggest` — чем добрать норму сегодня;
- `/review` — разбор дневного рациона;
- `/recipe продукты` — рецепт из продуктов дома;
- `/swap блюдо` — варианты замены;
- `/portion блюдо` — порция под остаток КБЖУ;
- `/coach вопрос` — персональная рекомендация;
- `/report` — отчёт, серия, достижения и прогноз;
- `/label` в подписи к фото — прочитать этикетку;
- `/reminders` — открыть настройки уведомлений;
- `/backup` и `/restore` — закрытые команды владельца.
- `/admin` — закрытая кнопка админ-панели для владельца.

## Ошибка SOCKS-прокси

Если анализ фотографии сообщает, что пакет `socksio` не установлен, закройте сервер и дважды нажмите `ИСПРАВИТЬ_PROXY_WINDOWS.bat`. В актуальной версии поддержка SOCKS также устанавливается автоматически вместе с остальными зависимостями.

## Запуск через Docker

```powershell
Copy-Item .env.example .env
docker compose up --build
```

## Подключение Mini App к Telegram

После размещения проекта на сервере с HTTPS:

1. В `.env` укажите `WEBAPP_URL=https://ваш-домен` и `DEV_MODE=false`.
2. Перезапустите приложение.
3. В BotFather откройте `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → **Configure menu button**.
4. Отправьте тот же HTTPS-адрес и название кнопки, например `Дневник питания`.

## Важная точность

Фотография не позволяет достоверно увидеть вес, масло, сахар и скрытые ингредиенты. Поэтому результат помечается как оценка, сохраняет допущения и может быть исправлен. Расчёт не является медицинской рекомендацией.
